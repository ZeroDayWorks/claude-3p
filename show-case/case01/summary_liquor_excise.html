พ.ร.บ. ฉบับที่ 2 และกฎกระทรวงการผลิตสุรา พ.ศ. 2568 มุ่งเน้นการปรับโครงสร้าง 3 มิติ

🏆

1. เพิ่มขีดความสามารถในการแข่งขัน

จัดประเภทใบอนุญาตเป็น 3 ระดับ (1, 2, 3) ตามขนาดกิจการ แทนการกำกับด้วยกำลังการผลิตขั้นต่ำ

ยกเลิกกำลังการผลิตขั้นต่ำ
🚀

2. เพิ่มโอกาสและความยืดหยุ่นทางธุรกิจ

เปิดสิทธิ์ให้สหกรณ์/วิสาหกิจชุมชน/ผู้ประกอบการรายย่อย ขอใบอนุญาตได้ทุกชนิดทุกประเภท

สนับสนุนสินค้าเกษตรในประเทศ
🛡️

3. คุ้มครองผู้บริโภคและสิ่งแวดล้อม

เปลี่ยนจากกำกับด้วย "ขนาดกำลังผลิต" → กำกับด้วย "คุณภาพและความปลอดภัย" ลดภาระ EIA

เปลี่ยนกระบวนทัศน์การกำกับดูแล

5ตารางเปรียบเทียบประเภทใบอนุญาต

ใบอนุญาตผลิตสุราเพื่อการค้า แบ่งเป็น 3 ประเภท (1, 2, 3) ตามขนาดกิจการและชนิดสุรา

ประเภท สุราแช่ชนิดเบียร์ สุราแช่อื่น (ไม่ใช่เบียร์) สุรากลั่นชนิดสุราขาว สุรากลั่นชนิดอื่น¹ สุราสามทับ
ประเภทที่ 1 ✓ ✓ ✓ ✓ ✓ (ผลิตเพื่อขายใน/ส่งออก/ใช้ในอุตสาหกรรม)
ประเภทที่ 2 ✓ ✓ ✓ ✓ —
ประเภทที่ 3 ✓ ✓ ✓ — —

¹ สุราผสม สุราปรุงพิเศษ สุราพิเศษ และสุรากลั่นอื่นที่มิใช่สุราขาวและสุราสามทับ

คุณสมบัติผู้ขอใบอนุญาต (ไม่ใช่เพื่อการค้า)

✓ บุคคลธรรมดา สัญชาติไทย อายุ ≥ 20 ปีบริบูรณ์
✓ สหกรณ์ / กลุ่มเกษตรกร วิสาหกิจชุมชน องค์กรเกษตรกร
✓ นิติบุคคล ตาม ป.พ.พ. ที่หุ้นส่วน/ผู้ถือหุ้นทุกคนเป็นบุคคลธรรมดาสัญชาติไทย
🎯 ข้อยกเว้น: กำหนดสัดส่วนความเป็นเจ้าของของบุคคลที่มิใช่สัญชาติไทยได้ · รัฐวิสาหกิจผลิตสุรา · ส่งเสริมผู้ประกอบอุตสาหกรรมรายย่อย

6การเปลี่ยนแปลงสำคัญ 5 มิติ

🔄

จาก "ขนาดกำลังผลิต" → "คุณภาพและความปลอดภัย"

  • ยกเลิกข้อกำหนดกำลังการผลิตขั้นต่ำทั้งหมด
  • ลดข้อจำกัด EIA
  • กำหนดมาตรฐานสถานที่/เครื่องจักรตามกฎหมายสาธารณสุข
📍

ผ่อนปรนเงื่อนไขที่ตั้งโรงงาน

  • โรงสุรากลั่นตั้ง < 100 เมตร จากแหล่งน้ำสาธารณะได้ หากมีระบบบำบัดน้ำเสียมาตรฐาน
  • ขยายช่องทางจำหน่ายสุราแช่ชนิดเบียร์นอกสถานที่
🌾

สนับสนุนสินค้าเกษตรในประเทศ

  • สหกรณ์/วิสาหกิจชุมชน/กลุ่มเกษตรกร ขอใบอนุญาตได้ทุกชนิดทุกประเภท
  • ผลิตสุราที่อาจมีสีหรือกลิ่นได้ โดยใช้วัตถุดิบในประเทศ
⛽

สุราสามทับ: ขยายช่องทางใช้งาน

  • ขายในราชอาณาจักร
  • ส่งออกนอกราชอาณาจักร
  • นำไปใช้ในอุตสาหกรรม (เชื้อเพลิง/อุตสาหกรรม) — ต้องได้รับอนุมัติรัฐมนตรี
📱

ดิจิทัลและอิเล็กทรอนิกส์

  • ส่งตัวอย่างฉลากผ่านระบบอิเล็กทรอนิกส์ (แจ้งผลใน 5 วันทำการ)
  • แสตมป์สุรามี QR Code ตรวจสอบย้อนกลับ
  • ลายมือชื่ออิเล็กทรอนิกส์รับรองผล
⏰

ขยายเวลาก่อสร้างเมื่อมีเหตุจำเป็น

  • ภัยธรรมชาติ
  • หน่วยงานรัฐออกกฎหมายใหม่
  • รออนุญาตจากหน่วยงานอื่น
  • เหตุจำเป็นอื่นที่มีหลักฐานชัดแจ้ง

รายการกฎหมาย/กฎระเบียบทั้งหมดที่ออกภายใต้ พ.ร.บ. ภาษีสรรพสามิต (ฉบับที่ 2) พ.ศ. 2568

# ชื่อกฎหมาย ระดับ ประเด็นหลัก ผลกระทบ/โอกาส
1พ.ร.บ. ภาษีสรรพสามิต (ฉบับที่ 2) พ.ศ. 2568พ.ร.บ.แก้ไขมาตรา 153 วรรคสามกรอบหลักการทั้งหมด
2กฎกระทรวงการผลิตสุรา พ.ศ. 2568กฎกระทรวงปรับปรุงหลักเกณฑ์การผลิตสุรากระทบผู้ผลิตทุกราย
3กฎกระทรวงกำหนดค่าธรรมเนียม (ฉบับที่ 3) พ.ศ. 2568กฎกระทรวงค่าธรรมเนียมใบอนุญาตกำหนดอัตราใหม่ให้รองรับ
4กฎกระทรวงชนิดและลักษณะแสตมป์สรรพสามิต (ฉบับที่ 3) พ.ศ. 2568กฎกระทรวงลักษณะแสตมป์สุราใหม่สุราแช่อื่น/สุราขาว/สุรากลั่นผสม
5ประกาศกรมฯ การออกใบอนุญาตผลิตสุราที่มิใช่เพื่อการค้าประกาศแบบ ภส. 04-01/1 และ 04-02/1 · พิจารณา ≤ 15 วันเปิดทางประชาชน/ชุมชน
6ประกาศกรมฯ การออกใบอนุญาตผลิตสุราเพื่อการค้าประกาศแบบ ภส. 04-01/04-02 · พิจารณา ≤ 30 วันรวมขั้นตอนตรวจประเมิน
7ประกาศกรมฯ ระบบบำบัดน้ำเสีย (< 100 ม. จากแหล่งน้ำ)ประกาศ3 โรงงานที่ตั้งใกล้แหล่งน้ำได้ผ่อนปรนที่ตั้งโรงงาน
8ประกาศกรมฯ มาตรฐานเครื่องจักร บุคลากร เครื่องมือประกาศมาตรฐานเฉพาะของอุปกรณ์ควบคุมคุณภาพสุรา
9ประกาศกรมฯ ขยายเวลาก่อสร้าง/เปิดดำเนินการประกาศ4 กรณีเหตุจำเป็นลดความเสี่ยงใบอนุญาตถูกยกเลิก
10ประกาศกรมฯ การผลิตสุราที่มิใช่เพื่อการค้าประกาศมาตรฐานคุณภาพ การส่งตัวอย่างกระบวนการผลิตที่โปร่งใส
11ประกาศกรมฯ การผลิตสุราเพื่อการค้าประกาศแบบแปลน กรรมวิธี ภาชนะบรรจุโรงงานผลิตหลายชนิดได้
12ประกาศกรมฯ การส่งตัวอย่างฉลากอิเล็กทรอนิกส์ประกาศตรวจสอบฉลาก e-Service · 5 วันทำการลดขั้นตอนเอกสาร
13ประกาศกรมฯ การใช้แสตมป์สุราที่มี QR Codeประกาศเจ้าหน้าที่ขีดฆ่าแสตมป์ e-Systemตรวจสอบย้อนกลับได้
14ประกาศกรมฯ การใช้แสตมป์สรรพสามิตสำหรับสินค้าสุราประกาศผู้เสียภาษีขีดฆ่าแสตมป์แสตมป์ปิดก่อนออกจากโรงงาน
15ประกาศกรมฯ การขอ/อนุญาตโอนใบอนุญาตประกาศใบอนุญาตอายุคงเหลือ ≥ 90 วันทางเลือกในการโอนธุรกิจ
16ระเบียบกรมฯ การควบคุมโรงอุตสาหกรรมผลิตสุราระเบียบตรวจทุก 6 เดือน / 1 ปีควบคุมโรงงานทุกประเภท
17ระเบียบกรมฯ การควบคุมโรงงานสุราแช่และสุราขาว ป.2-3ระเบียบใช้หลัก Risk Managementลดภาระผู้ประกอบการรายย่อย
18ระเบียบกรมฯ Direct Coding สำหรับเบียร์ ≥ 5,000 หน่วย/ชม.ระเบียบพิมพ์เครื่องหมายแสดงภาษีบนบรรจุภัณฑ์เพิ่มประสิทธิภาพและความโปร่งใส

11Key Insights · สรุปสาระสำคัญ

🎯 ใจความหลัก (Top 5)

  1. ยกเลิกกำลังการผลิตขั้นต่ำ เปลี่ยนเป็นกำกับด้วยคุณภาพและความปลอดภัย
  2. เปิดกว้างให้สหกรณ์/วิสาหกิจชุมชน ขอใบอนุญาตผลิตสุราเพื่อการค้าได้ทุกชนิดทุกประเภท
  3. แบ่งใบอนุญาตเป็น 3 ระดับ (1, 2, 3) ตามขนาดกิจการ
  4. สนับสนุนสินค้าเกษตรในประเทศ ผลิตเป็นสุราที่อาจมีสีหรือกลิ่นได้
  5. ดิจิทัลและโปร่งใส ฉลากอิเล็กทรอนิกส์ + แสตมป์ QR Code

📌 นัยสำคัญสำหรับผู้ประกอบการ

  • โรงสุรากลั่นตั้ง < 100 ม. จากแหล่งน้ำได้ หากมีระบบบำบัดน้ำเสีย
  • สุราสามทับ: ขยายช่องทางใช้ในอุตสาหกรรม (เชื้อเพลิง) ได้
  • ขยายช่องทางจำหน่ายเบียร์นอกสถานที่ (ภาชนะ ≥ 20 ลิตร)
  • โอนใบอนุญาตได้ (อายุคงเหลือ ≥ 90 วัน)
  • ใบอนุญาตเดิมยังคงใช้ได้ต่อ (บทเฉพาะกาล)
⚠️ การใช้งานกับข้อมูลของราชการ ต้องมีการตรวจสอบความถูกต้องด้วยตัวเองเสมอ
