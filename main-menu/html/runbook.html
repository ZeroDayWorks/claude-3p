Prerequisites

✓ สิ่งที่ต้องมี

  • Docker Desktop (หรือ Docker Engine + Compose v2)
  • โดเมนของตัวเองบน Cloudflare (ถ้าจะ deploy โหมด tunnel)
  • Google Cloud project + OAuth client (Desktop app) สำหรับ MCP

Start ระบบทั้งหมด

1 รันทุกอย่างด้วยคำสั่งเดียว

ที่ root ของ repo:

docker compose up -d

จะรวมทุก service: Authentik, Claude Gateway, LiteLLM, MCP, SearXNG, Grafana, OTel, และ Main Menu — cloudflared tunnel รวมอยู่ด้วย (ใช้ CLOUDFLARE_TUNNEL_TOKEN จาก gateway-auth/.env)

2 โหมด Cloudflare Tunnel (ถ้าใช้)

docker compose --profile tunnel up -d

ไม่ต้องใช้ flag พิเศษ — cloudflared tunnel รวมอยู่ใน default แล้ว ถ้าไม่ต้องการ tunnel ใช้ docker compose up -d --no-deps --exclude cloudflared

Stop ระบบทั้งหมด

1 Stop + เก็บ volumes

docker compose stop

หรือ docker compose down (เก็บ volumes ไว้)

2 ล้างข้อมูลด้วย (ระวัง!)

docker compose down -v

จะลบ volumes ทั้งหมด — ใช้เฉพาะตอนเริ่มใหม่

Generate secrets

1 Authentik secrets

cd gateway-auth
./authentik/scripts/generate-secrets.sh >> .env

จะได้ PG_PASS, AUTHENTIK_SECRET_KEY

2 LiteLLM master key

ตั้ง LITELLM_MASTER_KEY ใน gateway-auth/.env — ใช้ openssl rand -hex 32 สร้าง

OAuth MCP ครั้งแรก

1 วาง credentials

วาง credentials.json จาก Google Cloud Console ที่ mcp/gmail-mcp/secrets/

2 Gmail OAuth

cd mcp/gmail-mcp
docker compose --profile auth up -d gmail-auth
# เปิด http://localhost:3101 → login Google → บันทึก token
docker compose --profile auth down

3 Workspace OAuth

docker compose --profile auth-workspace up -d workspace-auth
# เปิด http://localhost:3103 → login Google
docker compose --profile auth-workspace down

Search Adapter

1 ทดสอบ

⚠ SSL error จาก Claude Desktop/Code

Adapter ใช้ mkcert cert (trusted ใน Windows). ถ้า Claude รันบน host ต้อง set:

# set ที่ User env (ทำครั้งเดียว)
[Environment]::SetEnvironmentVariable("NODE_EXTRA_CA_CERTS", "C:\Users\<user>\AppData\Local\mkcert\rootCA.pem", "User")

# ดู CAROOT
mkcert -CAROOT

# รีสตาร์ท Claude Desktop/Code หลัง set

ถ้ายังไม่ผ่าน ลองสร้าง cert ใหม่: mkcert localhost 127.0.0.1 ::1 แล้ว copy เป็น cert.pem / key.pem ใน cowork-search/certs/

Backup

1 Backup Authentik (PostgreSQL)

docker compose exec db pg_dump -U authentik authentik > backup-authentik-$(date +%Y%m%d).sql

2 Backup LiteLLM DB

docker compose exec litellm-db pg_dump -U litellm litellm > backup-litellm-$(date +%Y%m%d).sql

3 Backup volumes

docker run --rm -v claude-3p_database:/data -v $PWD:/backup alpine \
  tar czf /backup/authentik-data-$(date +%Y%m%d).tar.gz /data

Restore

1 Restore Authentik DB

cat backup-authentik-YYYYMMDD.sql | docker compose exec -T db psql -U authentik authentik

Troubleshooting

⚠ Container ไม่ขึ้น

docker compose ps -a
docker compose logs <service> --tail 100

⚠ Gateway 503 — JWKS fetch fail

ตรวจ Authentik ขึ้นหรือไม่ (docker compose ps server) — Gateway ใช้ cache ถ้ามี ถ้าไม่มีจะ fail closed

⚠ MCP 401 — token หมดอายุ

รัน OAuth ใหม่: docker compose --profile auth up -d gmail-auth → login อีกครั้ง

⚠ Port ชน

ตรวจ netstat -ano | findstr :4100 (Windows) หรือ lsof -i :4100 (Linux/Mac)

⚠ ลืม LITELLM_MASTER_KEY

ดูใน gateway-auth/.env — ถ้าหายต้อง generate ใหม่และ restart LiteLLM + Gateway

⚠ Build ล้มเหลว

docker compose build --no-cache <service>
