Demo Workspace Structure

Workspace แบ่งเป็น 4 หมวดเอกสาร + โฟลเดอร์ Output สำหรับเก็บผลลัพธ์:

Excise-Cowork-Demo/
├── 01-Law/            ← กฎหมายและเอกสารเกี่ยวกับการผลิตสุรา
│   └── กฎหมายภาษีสรรพสามิต_เกี่ยวกับ_การผลิตสุรา.pdf
├── 02-Manual/         ← คู่มือราชการ
│   └── คู่มือการใช้งานระบบงานแสดงเครื่องหมายการเสียภาษีV1.pdf
├── 03-Strategy/       ← แผนและยุทธศาสตร์
│   └── แผนยุทธศาสตร์กรมสรรพสามิต_5_ปี_พ.ศ._2564_-_2568.pdf
├── 04-Tax-Data/       ← ข้อมูลการจัดเก็บภาษี (CSV)
│   ├── การจัดเก็บภาษีสุรา.csv
│   └── การจัดเก็บภาษีรถยนต์.csv
└── Output/            ← ผลลัพธ์ที่ Claude สร้างขึ้น

01
สรุปกฎหมายภาษีสรรพสามิต — การผลิตสุรา
อ่านกฎหมาย → สรุป → สร้าง HTML + PowerPoint

Prompt

  • อ่านเอกสารทั้งหมดที่เกี่ยวข้องกับ "การผลิตสุรา"
  • สรุปสาระสำคัญ ขั้นตอน เงื่อนไข หน้าที่ และข้อควรระวัง
  • ใช้ภาษาที่เข้าใจง่าย
  • พร้อมระบุแหล่งข้อมูล
  • และสร้างผลลัพธ์เป็น HTML Visualization และ PowerPoint

Output Flow

Law / Regulation ↓ Claude Cowork ↓ Understand + Summarize ↓ HTML + PowerPoint
Use Cases: Summarize Law · Ask Question · Find Clause · Compare Documents · Explain for Non-Lawyer

02
ถามตอบจากเอกสารราชการ
Cross-document reasoning — รวมคำตอบจากหลายเอกสาร

ตัวอย่างคำถาม

  • การผลิตสุราต้องดำเนินการตามขั้นตอนใดบ้าง?
  • เอกสารกฎหมาย คู่มือ และยุทธศาสตร์กล่าวถึงเรื่องนี้อย่างไร?

Reasoning Flow

Question │ ▼ ┌──────────────┐ │ Claude Cowork│ └──────┬───────┘ │ ┌───────┼────────┐ ▼ ▼ ▼ Law Manual Strategy │ │ │ └───────┼────────┘ ▼ Consolidated Answer
จุดขาย: Cross-document reasoning — ไม่ได้ตอบจากเอกสารเดียว แต่รวมคำตอบจากกฎหมาย คู่มือ และยุทธศาสตร์

03
วิเคราะห์ข้อมูลการจัดเก็บภาษี
เปรียบเทียบ · แนวโน้ม · Anomaly · สร้าง Excel Summary

Prompt

  • วิเคราะห์ข้อมูลการจัดเก็บภาษีทั้งหมดใน Workspace
  • เปรียบเทียบแต่ละประเภท
  • หาแนวโน้มที่น่าสนใจ
  • ระบุข้อมูลผิดปกติที่ควรตรวจสอบ
  • และสร้าง Excise-Tax-Management-Summary.xlsx

Output Flow

Excel Files ↓ Analyze ↓ Compare / Trend / Anomaly ↓ Management Summary.xlsx
Excel Structure: Executive Summary · Monthly Trend · Tax Category · YoY Comparison · Anomaly · Raw Data

04
ตรวจสอบความถูกต้องของข้อมูล
AI Second Reviewer — ตรวจก่อนส่งต่อ แต่ยังมี Human Review

ตรวจสอบ

  • Missing Data
  • Duplicate
  • Total ผิด
  • Formula ผิด
  • วันที่ผิดปกติ
  • หน่วยข้อมูลไม่ตรงกัน
  • ข้อมูลขัดแย้งระหว่างไฟล์

ตัวอย่างผลลัพธ์

Document Validation Files checked 12 Passed 9 Warnings 2 Critical 1 ⚠ Vehicle-Tax.xlsx Detail : 12,453.22 Summary : 12,435.22 Difference: 18.00 Recommendation: ตรวจสอบข้อมูลก่อนจัดทำรายงาน
Concept: AI Second Reviewer — AI ช่วยตรวจงานก่อนส่งต่อ แต่ยังต้องมี Human Review ก่อนใช้จริง

05
สร้าง PowerPoint สำหรับผู้บริหาร
6 หน้า · เน้น Visualization · ระบุ Source

Prompt

  • จากผลการวิเคราะห์ทั้งหมด
  • สร้าง PowerPoint สำหรับผู้บริหาร 6 หน้า
  • เน้น Visualization
  • ใช้ข้อความให้น้อย
  • และแสดง Source ของข้อมูล

6 หน้า

01 Executive Summary 02 Excise Tax Overview 03 Revenue Trend 04 Tax Category Comparison 05 Key Findings / Issues 06 Recommendations
Flow: Raw Files → Analyze → Verify → Explain → Management PowerPoint

06
Email ถึงผู้บริหาร
Draft เท่านั้น · ห้ามส่งอัตโนมัติ

Prompt

  • จากข้อมูลและ Presentation ที่สร้างขึ้น
  • ร่าง Email สำหรับส่งผู้บริหาร
  • สรุปเฉพาะประเด็นสำคัญ
  • ระบุประเด็นที่ควรติดตาม
  • และรายการไฟล์แนบ
  • ให้สร้างเป็น Draft เท่านั้น ห้ามส่งอัตโนมัติ

Flow

Data ↓ Analysis ↓ Excel ↓ PowerPoint ↓ Email Draft
Constraint: Claude สร้าง draft เท่านั้น — ผู้ใช้ตรวจทานและส่งเองเสมอ

ข้อจำกัดและข้อแนะนำ

Governance

  • Claude Cowork ควรใช้งานภายใต้ Governance ขององค์กร
  • ต้องมีผู้ดูแลระบบและ AI Platform
  • ต้องกำหนด Authentication / Authorization
  • ต้องควบคุมสิทธิ์การเข้าถึง Workspace และ MCP
  • ต้องมี Audit Log และ Observability

การใช้งาน AI

  • ข้อมูลสำคัญควรมี Human Review ก่อนใช้งานจริง
  • AI อาจตีความข้อมูลหรือเอกสารผิดได้
  • งานที่ต้องใช้ Reasoning หลายเอกสารควรใช้ Model ระดับกลางถึงสูง
  • ควรมี LLM Gateway สำหรับควบคุม Model, Policy, Cost และ Fallback
  • งานที่มีผลทางกฎหมายหรือการตัดสินใจสำคัญ ไม่ควรใช้ผล AI โดยไม่มีการตรวจสอบจากผู้รับผิดชอบ
