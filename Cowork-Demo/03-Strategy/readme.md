# 03-Strategy — แผนและยุทธศาสตร์

แผนยุทธศาสตร์ของกรมสรรพสามิต ใช้สำหรับ Claude เชื่อมโยงผลการดำเนินงานกับยุทธศาสตร์

## เอกสาร

- `แผนยุทธศาสตร์กรมสรรพสามิต_5_ปี_พ.ศ._2564_-_2568.pdf`

## Use Cases

| Use Case | ตัวอย่าง Prompt |
|---|---|
| **Strategy Alignment** | "จาก Annual Report และข้อมูลการจัดเก็บภาษี มีผลการดำเนินงานใดที่สัมพันธ์กับยุทธศาสตร์ของกรมบ้าง?" |
| **Summarize Strategy** | "สรุปยุทธศาสตร์หลักของกรมสรรพสามิตใน 5 ปี (2564-2568)" |
| **KPI Tracking** | "จากข้อมูลภาษีใน 04-Tax-Data มีตัวชี้วัดใดที่สะท้อนยุทธศาสตร์ได้บ้าง?" |
| **Gap Analysis** | "มียุทธศาสตร์ใดที่ยังไม่มีข้อมูลสนับสนุนหรือตัวชี้วัดชัดเจน?" |
| **Output** | "powerpoint" |

## Concept

**Strategy Intelligence** — Claude ไม่ได้แค่สรุป แต่เชื่อมโยงข้อมูลการปฏิบัติจริงกับยุทธศาสตร์ระดับกรม
